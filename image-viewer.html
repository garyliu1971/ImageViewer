🖧 磁盘路径（需本地后端）直接指 C:\漫画、书.cbr、书.pdf； 后端由 python web_backend.py 提供，rar/cbr 走桌面版同款 rarfile + 7-Zip， PDF 走 PyMuPDF 按页渲染，进度与桌面版共用 image_viewer.json。
📦 压缩包 / 拖拽（需本地后端）选或拖 .rar .cbr .pdf 也行：浏览器拿不到真实路径，会先传到后端临时目录再按路径打开（单包上限 512MB）。
☁ 云端书库（部署在 /iv/ 时）打开 /iv/#open=书的相对路径，第一次填一个只读 WebDAV 账号； zip / cbz / epub 只按需取用到的页（HTTP Range），不整本下载。账号只存在这台设备的浏览器里。 账号框里的「跨设备续读」可把读到哪页写到 WebDAV 的进度文件夹，换设备打开同一本书自动接上。 📚 云端书架（起始页按钮 / 工具栏 / 快捷键 L）直接浏览书库目录，点 epub / cbz / zip 就读；读书时 N / P 或「上一本 / 下一本」切到同一文件夹里相邻的书。rar / cbr 要先转成 cbz，pdf 暂未支持。
断点续读页码、章节、双页 / 方向 / 去边 / 质感 存在浏览器本地（localStorage）。 浏览器拿不到磁盘绝对路径，所以重新打开时要再选一次同一个文件夹 / 同一个压缩包才会续上。
📱 手机 / VLC桌面版菜单「网页版（局域网，手机可访问）」或 python web_backend.py --lan；手机浏览器直接开终端里给的地址 （rar/cbz/pdf 都能用）。视频用手机 VLC 的「网络串流」：在网页版按 I 详情里有可一键复制的播放列表链接（/api/m3u）。
仍不支持tif / heic（浏览器不解码）、视频与实时字幕、网盘、投屏 → 用桌面版； rar / cbr / PDF 在后端模式下可用（磁盘路径 / 压缩包按钮 / 拖拽都行）

详细信息

云端书库账号

用来从本站同源的 WebDAV 读取书库里的 zip / cbz / epub（只发 Range 分段请求，不整本下载）。 请填只读账号。用户名已预填，只要输入密码。账号只保存在这台设备的浏览器里，不会写进网址。

跨设备续读（进度同步）

读到哪一页会写到 WebDAV 上的进度文件夹，换一台设备打开同一本书自动接上。书库账号是只读的， 写进度要另一个只能写进度文件夹的账号（留空 = 用上面的账号，没有写权限就同步不了）。进度文件夹留空 = 关闭同步。
